# To Do App

A simple and efficient To Do management application.

## Features

- Create, Edit and Delete tasks.
- Filter tasks by Name, Priority (High, Medium, Low) and State (Done/Undone).
- Sort tasks by Priority and/or Due Date.
- Show the Average Completion Time of the tasks in total, and by priority.

## Instructions to Run the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/Odin-BN/To-Do-App
   cd To-Do-App
   ```

2. Run the application using Docker Compose:
   ```bash
   docker-compose up
   ```

3. Access the application at `http://localhost:8080` (or the configured port).
